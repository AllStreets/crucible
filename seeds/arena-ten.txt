# Chosen by the author, not by a ranking, on the grounds that these are agents
# people actually run together: coding agents, orchestrators, a browser agent
# and a terminal agent. Phase 2a writes one entrypoint per agent, in the format
# SMADP's curated adapters already use.
#
# Two notes a later reader needs.
#
# opencode resolves to anomalyco/opencode. The repository most searches return,
# opencode-ai/opencode, is archived, and seeding it would have measured a dead
# project while appearing to measure a live one.
#
# continue and opencode are TypeScript. The generic recipe installs Python
# packages only, so both will fail for a reason that is about this harness and
# not about them. They are seeded anyway: the failure is a recorded observation
# and the honest starting point for a Node recipe.
